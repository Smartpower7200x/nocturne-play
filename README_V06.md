# NOCTURNE V0.6 视觉候选

这是一版**尚未覆盖线上 V0.5** 的视觉候选。目标是从单纯的暗色工具 UI 转向具有材质感、章节叙事感的故事档案馆。

## 修改
- 视觉色板：深墨绿、旧纸白、哑金、淡玉色；统一边框、标题和交互态。
- 首页：桌面双栏 / 手机封面卡片 + 大标题的阅读顺序；简化按钮形态与输入框轮廓。
- 牌面：原创 SVG 纹样、铜金边框、星图椭圆和版画式符号。仅是原创故事卡，不是传统 78 张塔罗。
- 抽牌与揭示：扩宽揭示页三张卡片，增强三张结果的视觉份量；保留原有弧形牌轮与洗牌状态机。
- 故事页：旧纸信笺作为结局重点，其他内容保持低对比编辑式排版。

## 不变
- 三套主题、抽牌逻辑、角色命名、结局选择、改写最后一张、复制、好友同题、PNG 导出。
- 无外部依赖，不增加远程字体或性能昂贵的 SVG 滤镜。

## 验收
Chromium 393×852 / 360×780 / 1280×800：页面可渲染、选择3张及结果生成、无横向溢出、无 JS 错误。三个主题单独回归：3张卡、结局、改写一次、PNG 文件签名校验通过。**真机 Android FPS、线上链接、分享链路不在本轮验收范围内**。

## 发布策略
当前是候选，先交付预览，不覆盖已上线 main；需要确认设计方向后再合并。
